# TSB Artifacts Plus
神器を追加する The Sky Blessing用二次創作データパック

## 説明
新たな神器を追加します。  
追加された神器は全てシャード加工機から入手できます。

## 導入方法
導入したいワールドフォルダ内のdatapacksフォルダを開き、  
datapacksフォルダ内にTSB Artifacts Plusを追加します。

## 注意点
・**TSBバージョンは1.0.6にのみ対応**  
・ゲームバランスが破壊される可能性があります。  
・他の神器追加系の二次創作データパックとは競合する可能性が高いです。  
・途中導入可能ですが、念のためバックアップを取ってから導入することを推奨します。    
・このデータパックを入れた状態で不具合が発生した場合は、TSB公式のサポート対象外になります。
